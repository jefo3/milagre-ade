## What to build

Provide a global chat from which the user can message any active agent session by selecting an explicit recipient. The user can attach relevant context from connected worktrees without leaving the workspace.

## Acceptance criteria

- [ ] The user can select an active agent as the message recipient.
- [ ] Messages reach only the explicitly selected session.
- [ ] Relevant connected-worktree context can be included.
- [ ] The UI makes the selected recipient visible.
- [ ] Important messages are never silently routed by inference.

## Blocked by

- Ticket 3: Shared context between connected agents.
