## What to build

Show registered worktrees as nodes in an interactive canvas. The user can arrange nodes, drag between two worktrees, choose a relationship type, and save the connection as bidirectional, persistent or temporary.

## Acceptance criteria

- [ ] Worktrees appear as identifiable canvas nodes.
- [ ] A connection can be created by dragging between nodes.
- [ ] The user chooses dependency, information, review or blocking.
- [ ] Persistent and temporary connection lifecycles are preserved.
- [ ] Connection creation is covered by an end-to-end behavior test.

## Blocked by

- Ticket 1: Bootstrap local ADE with projects, worktrees and agent sessions.
