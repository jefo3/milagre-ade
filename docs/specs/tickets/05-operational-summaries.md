## What to build

Show concise, human-readable operational status for each agent and connection while preserving the underlying evidence. The user can inspect summary, events, terminal output, diffs and raw agent output.

## Acceptance criteria

- [ ] The default view shows current state, decisions, changes, risks, blockers and next action.
- [ ] Summaries use concise, simpler language.
- [ ] Raw output remains accessible through an expanded or tabbed view.
- [ ] Structured events remain distinct from generated summaries.
- [ ] The canvas highlights agents that need attention.

## Blocked by

- Ticket 3: Shared context between connected agents.
