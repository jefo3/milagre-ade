# Code of Conduct

Milagre is a small open-source project and should be a welcoming place to work.

Participants are expected to:

- be respectful and constructive;
- discuss ideas and code without personal attacks;
- welcome different backgrounds and experience levels;
- accept good-faith corrections;
- keep feedback specific, actionable and relevant.

Harassment, discrimination, threats, doxxing and deliberate disruption are not acceptable.

Report concerns privately to the repository maintainer. Reports will be reviewed in good faith and handled as confidentially as practical.
